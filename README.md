# splitipv6

Split filesystem ipv6 paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/splitipv6/

## Install / run

```bash
git clone https://github.com/theworker02/splitipv6.git
cd splitipv6
node src/cli.js
node --test
```
